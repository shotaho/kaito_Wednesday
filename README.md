# 水曜日のカイト

カイトくんが水曜日の朝6時から夕方6時まで凧を揚げつづける、ブラウザで遊べる凧揚げゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド不要・依存なし)。

| 操作 | 内容 |
| --- | --- |
| クリック / タップ / Space / ↑ を押している間 | 糸を引いて凧が上昇 |
| はなす | 凧がゆっくり下がる |
| ← → | 凧の前後位置を調整 |

- **よける**: カラス・雷雲・電線・地面(ぶつかると凧が1つ減る。3つで終了)
- **あつめる**: しずく +10点、水曜の星 +100点
- 夕方6時まで凧を揚げきるとクリア。残った凧1つにつき +300点
- 時間が進むと空の色が朝→昼→夕方に変わり、障害物が増えます
- ベストスコアはブラウザに保存されます

## 調整ポイント

`index.html` のスクリプト冒頭にある定数で調整できます。

- `DURATION`: 1日(6:00→18:00)の長さ(秒)
- `MAX_LIVES`: 凧の数
