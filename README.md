# 水曜日のカイト

頭のお皿にのったボールを、おもちゃの刀や拾った武器で落とし合う、多人数対多人数の3Dチームバトルゲームです。ブラウザで `index.html` を開くだけで遊べます(ビルド不要。3D表示には [three.js](https://threejs.org/) r128 を CDN から読み込みます)。

**遊ぶ:** https://shotaho.github.io/kaito_Wednesday/

遊び方は2つあります。

- **ひとりで遊ぶ**: あなた(青組)+味方ボット vs 赤組ボット(3対3 / 5対5 / 8対8)
- **同じWiFiで対戦**: スマホやパソコンを同じWiFiにつないで、みんなで対戦。青組・赤組を自分で選べるので、同じチームで協力も、敵チームで対決もできる。足りない人数はボットが入る

## 同じWiFiで対戦する

1. 全員が https://shotaho.github.io/kaito_Wednesday/ を開き、「なまえ」を入れる
2. 1人(ホスト)が **部屋をつくる** を押す → 4文字の **部屋コード** が出る
3. ほかの人はコードを入れて **部屋に入る** を押す
4. 部屋の画面で **青組に入る / 赤組に入る** を選ぶ(同じチームにも敵チームにもなれる)
5. ホストが各チームの人数を選んで **バトル開始**

しくみ:

- ホストの端末がゲームを動かし、参加者は操作を送って画面を受け取る(1秒に約20回)
- 最初の接続の手続きだけ PeerJS の公開サーバー(インターネット)を使い、つながったあとのゲームのデータは同じWiFiの端末どうしで直接やりとりする(WebRTC)
- 途中で抜けた人の選手は、ボットが代わりに動かす
- 学校や公共のWiFiなど、端末どうしの通信を止めているネットワークではつながらないことがある
- claude.ai のプレビュー画面では通信対戦は使えない(GitHub Pages 版で遊ぶ)

## ルール

- **お皿**: 各プレイヤーの頭にお皿があり、ボールが3個のっている
- **攻撃**: 道具でお皿をたたくとボールが落ちる。体当たりなど、ほかの接触は禁止(体はぶつかっても押し返されるだけ)
- **牢屋**: お皿のボールが0になると、相手陣地の牢屋へ送られる
- **復活**: ボールを持った仲間が牢屋の柵にさわると、ボールを1個もらって復活(お皿にボール1個で再出発)
- **武器**: 最初はおもちゃの刀。マップの箱(草むらの中に隠れているものも)を攻撃すると、バット・物干し竿・ピコハン・ボールが出てくる(からっぽもある)。箱はしばらくすると中身が変わって復活
- **捕球**: 最初はボールを拾えない。マップに隠された **捕球スイッチ**(草むらの中や木の陰。近づかないと見えない)を踏むとグローブがもらえ、ボールを拾えるようになる。空中を飛んでいるボールもキャッチできる。牢屋に入るとグローブはなくなる
- **ボール**: 落ちたボールやマップに出てくるボールを拾って貯める。牢屋に入ると手持ちボールはその場にこぼれる
- **召喚**: 手持ちボールを100個使うと、戦車・ヘリコプター・飛行機のどれかがランダムに来て相手を攻撃
  - 戦車: 相手を追いかけてボールの砲弾を撃つ
  - ヘリコプター: 相手の上空からボール爆弾を落とす
  - 飛行機: マップを3回横切って爆撃する
- **勝敗**: 相手チームを全員牢屋に入れたら勝ち。4分の時間切れなら残り人数、同じならお皿のボールの合計で決着

| 武器 | 特徴 |
| --- | --- |
| おもちゃの刀 | 標準 |
| バット | 一撃でボール2個。振りが遅い |
| 物干し竿 | とても長いが、当たる角度がせまい |
| ピコハン | 短いが連打できる |

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD(↑↓ でも前後) | 画面左側をドラッグ |
| 視点 | マウス(画面クリックでロック、Esc で解除)/ ← → | 画面右側をドラッグ |
| 攻撃 | クリック / Space / J(前方の近い相手に自動で向く) | 攻撃ボタン、または画面右側をタップ |
| 召喚 | Q / 召喚ボタン | 召喚ボタン |

## 調整ポイント

`index.html` のスクリプト冒頭の定数で調整できます。

- `PLATE_MAX`: お皿のボール数
- `VEHICLE_COST`: 召喚に必要なボール数
- `MATCH_TIME`: 試合時間(秒)
- `WEAPONS`: 武器ごとの射程・角度・間隔・落とすボール数
